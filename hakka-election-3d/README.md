# 客家選情 3D 地圖 — 第二階段技術原型

延續 `../Hakka_3D_map`（第一階段，2026-07-24）。第一階段版本保持原樣，備份在 `../_備份/Hakka_3D_map_20261008`。
計畫文件：Obsidian `10.projects/客新聞/客新聞選舉網站/3D地圖新計畫.md`

## 執行
雙擊 `start.bat`（需 Python），或 `python -m http.server 8131` 後開 http://localhost:8131。
不能直接雙擊 index.html（TopoJSON 走 fetch）。函式庫全在 `lib/`，可離線執行。

## 技術
- Three.js r186（WebGLRenderer）、camera-controls 3.1.2、GSAP 3.15.0，以 importmap 載入本地檔，暫不建置（交付時再導入 Vite）
- d3-geo + topojson 投影與擠出，沿用第一階段管線與資料

## 本階段驗證的效果
- 場景階層：地圖 → 縣市群組（整縣升起 6）→ 鄉鎮 Mesh（縣內再升 0.4–5.5，依客家比例或客家人口）
- 弧線運鏡：目標點直線移動、鏡頭距離中段拉高、方位走最短路徑；GSAP power2.inOut
- 自動構圖：依縣市主體範圍（排除烏坵、東沙等遠離本體的離島）與「扣掉面板後的可見區域」計算距離；以 view offset 讓縣市落在可見區正中央
- 招牌視角：`PRESETS`（花蓮、臺東、宜蘭、離島）
- 觸控手勢對標 Google Maps 3D：單指拖曳＝平移、雙指＝開合縮放＋拖曳旋轉（`setTouchScheme`）；觸控裝置的 HUD 提示文字另寫
- 到位後：鏡頭全不鎖（依客戶決定），只有 `MAP_BOUNDS` 邊界約束注視點不離開地圖範圍；讀者可平移到其他縣市再點選
- A→B 直接切換：前一縣下降與新縣升起同步；其他縣淡化
- 色階（避開藍綠，取氣象署累積雨量圖例黃色以上區段）：淺黃 → 黃橙 → 紅 → 深紅 → 深紫（`STOPS`）；顏色跟著所選指標（客家比例／客家人口）重算，上限見 `COLOR_MAX`；總覽左上有圖例
- 標籤：縣市名／鄉鎮名以 DOM 投影，依重要度防重疊；聚焦某縣時其他縣市名仍顯示（淡化），被聚焦縣改顯示鄉鎮名
- 支援 prefers-reduced-motion（動畫縮到 0.15 秒內）
- 手機：地圖佔上方 2/5，資訊抽屜佔 3/5（統計列四格一列、字縮小），抽屜以「高度」切換而非位移，半屏時可捲動範圍＝可見範圍；拖曳標題列／把手或點把手可拉到全屏（92vh），全屏時內容捲到頂再下拉即收回。手機不顯示下方縣市列，只靠點地圖
- 澎湖／金門／連江（馬祖）各放進一個立體方框，沿本島西側由北到南排列（`ISLAND_BOX`），整縣依方框縮放、不照實際位置與比例；方框底板整個可點。離主體太遠的島（金門的烏坵）隱藏
- 總覽構圖（`overviewPose`）：接近俯視（polar 0.42），用實際投影範圍迭代修正距離與注視點，讓本島＋離島方框佔可見區約 94% 高／92% 寬並置中；版面在手機／桌機模式切換時自動重新構圖
- 鄉鎮長條圖：客家人口模式＝佔全縣客家人口比例（全縣加總 100%，標籤附佔比）；客家比例模式＝絕對比例（滿條 100%）；客家人口少於 1,000 人者顯示「少於 1,000 人」
- 除錯介面：`window.__HAKKA3D__.focusCounty('新竹縣')`、`.overview()`

## 已知限制（下一階段處理）
- 352 個鄉鎮各一 Mesh＋材質，繪製次數多；手機效能未實機測，之後改 BatchedMesh 或每縣合併幾何
- 尚未加後製（Bloom）、尚未做按需渲染
- 金門／澎湖／連江資料以縣為單位，聚焦時沒有鄉鎮起伏
- 候選人兩張卡片並列（插畫與基本資料縮小）；客家政策兩欄並列，各只放一句標題（`policy`）＋深色「看完整政策」按鈕另開新頁連到專訪（`link`；未填時先連到客新聞首頁 https://hakkanews.tw/）
- 指標切換（客家比例／客家人口）：面板內與地圖上的浮動按鈕共用同一狀態；浮動按鈕跟著聚焦縣市走，貼在縣市投影範圍正下方（`placeFloat`，每幀更新，夾在可見區內），抽屜全屏時隱藏
- 側牆向下延伸 `SKIRT`，縣市升起時不露出與鄰縣之間的海面縫隙
- 畫布或視窗尺寸為 0（被隱藏）時沿用最後一次有效尺寸，構圖不會退化
- 面板的選票數、兩黨候選人（插畫、黨籍、年紀、現職、經歷）、客家政見為佔位版面，資料在 `data/election.js`，待客戶提供後逐縣市替換
