# 客家選情 3D 地圖 — 第二階段技術原型

延續 `../Hakka_3D_map`（第一階段，2026-07-24）。第一階段版本保持原樣，備份在 `../_備份/Hakka_3D_map_20261008`。
計畫文件：Obsidian `10.projects/客新聞/客新聞選舉網站/3D地圖新計畫.md`

## 執行
雙擊 `start.bat`（需 Python），或 `python -m http.server 8131` 後開 http://localhost:8131。
不能直接雙擊 index.html（TopoJSON 走 fetch）。函式庫全在 `lib/`，可離線執行。

## 技術
- Three.js r186（WebGLRenderer）、camera-controls 3.1.2、GSAP 3.15.0，以 importmap 載入本地檔，暫不建置（交付時再導入 Vite）
- d3-geo + topojson 投影與擠出，沿用第一階段管線與資料

## 本階段驗證的效果
- 場景階層：地圖 → 縣市群組（整縣升起 6）→ 鄉鎮 Mesh（縣內再升 0.4–5.5，依客家比例或客家人口）
- 弧線運鏡：目標點直線移動、鏡頭距離中段拉高、方位走最短路徑；GSAP power2.inOut
- 自動構圖：依縣市主體範圍（排除烏坵、東沙等遠離本體的離島）與「扣掉面板後的可見區域」計算距離；以 view offset 讓縣市落在可見區正中央
- 招牌視角：`PRESETS`（花蓮、臺東、宜蘭、離島）
- 到位後：水平旋轉不鎖（可繞縣市 360°），限制俯仰與距離範圍、停用平移
- A→B 直接切換：前一縣下降與新縣升起同步；其他縣淡化
- 標籤：縣市名（總覽）／鄉鎮名（聚焦）以 DOM 投影，依重要度防重疊
- 支援 prefers-reduced-motion（動畫縮到 0.15 秒內）
- 手機：地圖佔上方 2/5，資訊抽屜佔 3/5（統計列四格一列、字縮小）；拖曳標題列／把手或點把手可拉到全屏（92vh），全屏時內容捲到頂再下拉即收回。手機不顯示下方縣市列，只靠點地圖
- 澎湖／金門／連江以示意位移靠近本島（`ISLAND_SHIFT`，不照實際比例）；另有放大 20% 的透明圓形感應區（半徑自動夾住：離本島至少 3 單位、離島之間不重疊）
- 鄉鎮長條圖：客家人口模式＝佔全縣客家人口比例（全縣加總 100%，標籤附佔比）；客家比例模式＝絕對比例（滿條 100%）；客家人口少於 1,000 人者顯示「少於 1,000 人」
- 除錯介面：`window.__HAKKA3D__.focusCounty('新竹縣')`、`.overview()`

## 已知限制（下一階段處理）
- 352 個鄉鎮各一 Mesh＋材質，繪製次數多；手機效能未實機測，之後改 BatchedMesh 或每縣合併幾何
- 尚未加後製（Bloom）、尚未做按需渲染
- 金門／澎湖／連江資料以縣為單位，聚焦時沒有鄉鎮起伏
- 候選人卡片整張可點（含經歷區），點卡片或下方切換鈕都能換政策
- 面板的選票數、兩黨候選人（插畫、黨籍、年紀、現職、經歷）、四大客家政策為佔位版面，資料在 `data/election.js`，待客戶提供後逐縣市替換
